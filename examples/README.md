# 예제와 사용법

## 파일

| 파일 | 무엇을 보여주나 |
|---|---|
| `plot_fig3.py` | 2패널 그림 하나. **합치기용이 아니다** — `plot(ax)`가 없다 |
| `panel_uptake.py` | 흡수 곡선. 범례, 긴 y라벨 |
| `panel_dose.py` | seaborn hue. `(범례 전용)` artist가 나온다 |
| `panel_recovery.py` | 배출 곡선. y라벨이 일부러 짧다 |
| `panel_bars.py` | 오차막대 막대. patches 그룹이 트리에 나온다 |

`panel_*.py` 넷은 전부 `plot(ax)`를 노출하므로 **서로 합칠 수 있다**.
각각 단독 실행도 된다:

```bash
python examples/panel_uptake.py
```

## 1. 그림 하나 열고 고치기

```bash
figtune examples/plot_fig3.py
```

- **클릭** — 제목·축라벨·선·범례·축 무엇이든 눌러 고른다
- **끌기** — 제목·범례·축 본체를 잡아 옮긴다. 종이가 따라 맞춰진다
- **한 번 클릭 후 그대로 떼기** — 글자 위에서는 그 자리에 캐럿이 뜬다
- **더블클릭** — 그 대상의 전체 설정 대화상자
- **모서리** — 축을 고른 뒤 모서리를 끌면 크기가 바뀐다
- **Esc** — 선택 해제

오른쪽 **속성** 탭에서 값을 고치고, **코드** 탭에서 생성될 코드를 본다.

### 여러 개 함께 고르기

- **Shift+클릭** 또는 **Ctrl+클릭** — 선택에 더하거나 뺀다 (PowerPoint와 같다)
- 왼쪽 **트리**에서는 Shift가 범위, Ctrl이 개별이다
- 여럿을 고르면 속성 패널에 **공통 속성만** 뜨고, 고치면 전부에 들어간다
- 값이 서로 다른 칸은 비어 있고 라벨에 `*`가 붙는다
- 고른 것들을 함께 끌면 통째로 움직인다

### 저장

`Ctrl+S`. 두 파일이 생긴다.

- `plot_fig3.figtune.yaml` — 편집 내용(spec)
- `plot_fig3_style.py` — 그것을 적용하는 **순수 matplotlib 코드**

원본 `plot_fig3.py`는 **절대 수정되지 않는다**. 저장할 때 원본 맨 끝에
`apply_style(fig)` 한 줄만 붙는다(훅). 그 뒤로는 원본을 그냥 실행해도
편집이 반영된다 — figtune 없이.

## 2. 여러 그림을 하나로 합치기

### GUI에서

```bash
figtune examples/panel_uptake.py
```

1. **파일 → 열기 (Ctrl+O)** 로 합칠 패널들을 탭으로 연다
   (`panel_dose.py`, `panel_bars.py` …)
2. **파일 → 그림 합치기 (Ctrl+M)**
3. 격자 위를 훑어 몇 행 몇 열인지 고른다. 누르면 정해진다
4. 조립 화면에서
   - 빈 칸의 **`+`** 를 눌러 열려 있는 탭 중 하나를 놓는다
   - 칸 여러 개를 **끌어 고른 뒤 "칸 묶기"** — 2칸짜리 패널이 된다
   - 묶은 칸을 되돌리려면 그 칸을 고르고 **"칸 나누기"**
   - 잘못 놓았으면 **"칸 비우기"**
5. 빈 칸이 없어지면 **저장하고 종료** 가 켜진다. 누르면 파일을 정하고,
   결과가 **새 탭**으로 열린다

예: 2×2에서 위 두 칸을 묶으면 이런 그림이 나온다.

```
┌─────────────────────────┐
│  (a) Uptake             │   ← 2칸짜리
├────────────┬────────────┤
│ (b) Dose   │ (c) Bars   │
└────────────┴────────────┘
```

### 명령줄에서 (균일 격자만)

```bash
figtune merge examples/panel_uptake.py examples/panel_dose.py \
              examples/panel_bars.py -o merged.py
figtune merged.py
```

### 병합 결과에 대해

생성된 `merged.py`는 **그 파일 하나로 완결된다.** 각 패널의 코드가 그 안에
복사되어 들어가므로 원본 패널 파일을 지우거나 옮겨도 그림이 그려진다.
논문에 딸려 보낼 때 파일 하나만 보내면 된다.

대가가 하나 있다. **나중에 패널을 고쳐도 병합 결과에는 반영되지 않는다.**
다시 합쳐야 한다.

병합 결과는 평범한 matplotlib Figure이므로 figtune으로 열어 통째로 편집할
수 있다. `(a)(b)(c)` 라벨도 편집 대상이다.

## 3. 합치려면 패널이 갖춰야 할 형태

`ax`를 받는 함수 하나면 된다.

```python
import matplotlib.pyplot as plt

def plot(ax):                 # 이름은 plot / draw / render / make_plot 아무거나
    ax.plot(...)
    ax.set_xlabel("Time (h)")

if __name__ == "__main__":    # 단독 실행도 그대로 된다
    fig, ax = plt.subplots()
    plot(ax)
    plt.show()
```

없으면 figtune이 무엇이 빠졌는지 알리고 멈춘다.

**데이터 경로는 병합할 때 자동으로 맞춰진다.** 패널이
`pd.read_csv('data.csv')`처럼 상대 경로로 읽으면, 병합 파일에서 보이는
경로(`'b/data.csv'`, `'../siteA/data.csv'` …)로 고쳐 옮긴다. 그래서 데이터가
여러 폴더에 흩어져 있어도 합쳐진다. **원본 파일은 고치지 않는다** — 고쳐지는
것은 병합 파일 안의 사본뿐이다.

절대 경로로 바꾸지는 않는다. 이 PC에서는 편하지만 폴더째 다른 사람에게
보내는 순간 깨지기 때문이다. 대신 병합 파일 하나만 따로 옮기면 경로가
어긋난다 — 그때는 다시 합치면 된다.

경로를 변수로 만드는 경우(`pd.read_csv(NAME)`)는 무엇이 될지 알 수 없어
고칠 수 없다. figtune이 그 경우만 알린다.

**`__file__`은 쓰지 말 것.** 병합 파일 안으로 옮겨지면 그 값이 병합 파일의
경로가 되어 다른 데이터를 읽게 된다. figtune이 이 경우를 거부한다. 경로는
상수나 인자로 두면 된다.

## 4. 알아두면 좋은 것

**확대·이동은 편집이 아니다.** 캔버스 위 툴바의 확대·이동은 spec을 건드리지
않는다. 지금 보고 있는 범위를 남기려면 툴바의 **"범위 적용"** 을 누른다.
그 모드가 켜져 있는 동안에는 편집 제스처가 동작하지 않는다.

**종이는 내용에 맞춰진다.** 무언가를 끌면 종이(figure)가 내용 + 0.1in에 다시
맞춰진다. 그래서 첫 끌기에 원본 스크립트가 남긴 여백이 사라질 수 있다.

**실행 취소는 문서마다 따로다.** 탭을 옮겨도 그 탭의 이력이 유지된다.

**글꼴은 내려받지 않는다.** 한글 글꼴이 없으면 설치 명령만 알려준다.
도구가 조용히 외부에 접속하지 않는다.

**원본이 바뀌면 알린다.** 스크립트를 고쳐 선의 순서가 밀리면, figtune이
지문을 대조해 어긋난 항목과 짐작되는 새 위치를 알린다. 조용히 엉뚱한
선에 색이 칠해지는 것이 이 도구의 가장 위험한 실패이기 때문이다.
